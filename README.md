# Frontend Development Internship Projects

This repository contains the frontend projects developed as part of my Frontend Development Internship using HTML, CSS, and JavaScript.

## Projects

### 1. SmartCalc

SmartCalc is a responsive all-in-one calculator web application designed with multiple calculation and conversion functionalities. It provides a clean, interactive, and user-friendly interface with a focus on responsive design and smooth user interaction.

**Technologies Used:**
- HTML5
- CSS3
- JavaScript

### 2. Image Gallery

Image Gallery is a responsive web application designed to display a collection of preloaded default images in a clean and interactive layout. The project focuses on responsive design, visual presentation, and user-friendly navigation.

**Technologies Used:**
- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the required project folder.
3. Open `index.html` in a web browser.
4. Explore the application.

## Purpose

These projects were developed to gain practical experience in frontend development, responsive web design, JavaScript functionality, and creating interactive user interfaces.
